# Asset sources

- `favicon.svg`: original geometric mark, two forward strokes in the portfolio's light/dark blue tokens. Replaces the initials icon after the user rejected the RB identity. No third-party logo or artwork is used.

- `hammerpulse-logo-{light,dark}.svg`: original vector wordmarks copied unchanged from `work/meta-ads-data/src/weekly-report-web/hammerpulse-logo-horizontal-{light,dark}.svg`. Used for project identity on the homepage and detail page.
- The homepage uses original project/university logos for ClassVision, USMctf, RAK Fitness, Cheen Tea, and HammerPulse. Other projects use native typographic name marks, not invented interface screenshots or third-party brands.

- `hammerpulse-reporting-{light,dark}.png`: browser captures of HammerPulse's real Reporting Workspace at `/reports/weekly/meta-weekly-reporting`, using its local `scripts/frontend-fixture-server.mjs`. Source project: `work/meta-ads-data`. Captured at 1440 × 960 on October 6, 2026. Account names, campaign names, and IDs were replaced in the page with demonstration identities before capture. Values come from synthetic fixtures. The product's own horizontal logo was used on the application's light logo plate. These are interface evidence, not client performance claims.
- `hammerpulse-metrics-{light,dark}.png`: element captures of that fixture's weekly metrics matrix, 1072 × 1040, with the same anonymization. No generated interface imagery is used.
- `classvision-logo.webp`: optimized copy of the repository's existing `classvision-logo.png`, resized to 640 pixels wide. This is the University of Southern Mindanao seal, used for the university thesis; it is not a dedicated ClassVision brand. The original remains available.
- Portrait and other displayed project logos are the existing, user-provided repository assets. Legacy dashboard mockups are retained but are not used by the portfolio.
- `fonts/dm-sans-latin.woff2`: DM Sans variable Latin font, from [Google Fonts](https://fonts.google.com/specimen/DM+Sans). Source: `https://fonts.gstatic.com/s/dmsans/v17/rP2Hp2ywxg089UriCZOIHQ.woff2`.
- `fonts/space-grotesk-latin.woff2`: Space Grotesk variable Latin font, from [Google Fonts](https://fonts.google.com/specimen/Space+Grotesk). Source: `https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4Cw.woff2`.

Both fonts use the SIL Open Font License; their license files are stored beside them. Fonts and images are served locally.
